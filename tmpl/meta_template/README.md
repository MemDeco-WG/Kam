This is a KernelSU metamodule template generated by Kam.
Metamodules are used when you need to modify files in the `/system` partition using overlayfs.

## Features

- System modification via overlayfs
- KernelSU compatible
- Built with Kam

## Installation

1. Build the module using `kam build`
2. Flash the generated zip file in KernelSU Manager
3. Reboot
